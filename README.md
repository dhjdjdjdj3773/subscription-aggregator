# VPN Key Aggregator 🌐

Простой и быстрый веб-краулер для автоматического сбора, парсинга и переименования бесплатных конфигураций VPN (VLESS, VMess, Shadowsocks, Trojan) из открытых источников.

## 🚀 Живой демо-сайт
Проект развернут на GitHub Pages. Вы можете открыть его по ссылке в настройках вашего репозитория.

## ✨ Особенности
- **Автоматический парсинг:** Скрипт в реальном времени загружает актуальные конфигурации из публичных репозиториев.
- **Умное переименование:** Автоматически очищает оригинальные названия серверов и заменяет их на понятные `Бесплатный VPN #№`. Название меняется как на сайте, так и внутри самого копируемого ключа.
- **Копирование в один клик:** Удобная кнопка для мгновенного сохранения ключа в буфер обмена.
- **Обход CORS:** Использует встроенный прокси-сервер для выполнения запросов напрямую из браузера без необходимости развертывания бэкенда.
- **Адаптивный дизайн:** Интерфейс оптимизирован для мобильных устройств и ПК, имеет современную темную тему.

## 🛠 Как использовать ключи
1. Скопируйте нужный ключ с сайта.
2. Скачайте любой совместимый VPN-клиент:
   - **Windows / macOS:** v2rayN, Nekobox, Amnezia VPN, Sing-box.
   - **Android / iOS:** v2rayNG, Streisand, v2box, Sing-box, FoXray.
3. Импортируйте ключ из буфера обмена в приложение и нажмите «Подключиться».
